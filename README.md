# AIark.top

任务驱动的 AI 工具导航网站。当前收录 641 个 AI 工具，覆盖 29 个分类，用户可以按任务、分类、价格、地区和能力筛选，并收藏、对比、复制当前筛选链接。

## 功能

- 任务快捷筛选：找资料、写论文、做海报、做视频、写代码、做 PPT、Web MVP、自动化、本地部署、简历优化、AI 编程、电商运营。
- 多维过滤：分类、价格、地区、API、团队协作、本地/开源、移动端友好。
- 对标扩容：分类扩展到模型平台、提示词资源、学习教育、数据分析、无代码建站、营销电商、数字人、AI 检测评测、法律财税等方向。
- 任务建议：输入任务或选择场景后，自动推荐匹配的工具链，并支持套用筛选或加入对比。
- 收藏和对比：收藏保存在浏览器本地，对比栏最多展示 4 个工具。
- 活跃筛选条：当前条件可见，并可单独移除某一项筛选。
- 可分享筛选：复制当前筛选链接，便于把特定工具集合发给别人。
- 工具组合套用：论文速读、短视频生产、Web MVP、Agent 工作台、本地隐私等组合可一键筛选。
- 侧边栏模式：桌面端支持完整、简洁、隐藏三态，移动端使用抽屉式分类菜单。
- 主题系统：支持浅色、深色、跟随系统，并保存用户偏好。
- 卡片视图：支持标准视图和紧凑视图，偏好保存到浏览器本地。
- SEO 可读内容：首页保留静态分类说明，并通过构建脚本生成 682 个分类、工具详情和场景静态页面。
- Agent 工具链：收录 Claude Code、OpenClaw、Hermes Agent 等开发和自动化工具。
- 静态部署：无后端依赖，可直接部署到 Vercel。

## 本地打开

直接打开 `index.html` 即可使用。

## 本地服务预览

```powershell
npm run dev
```

默认地址：`http://localhost:4173`

## 检查

```powershell
npm run check
```

## 生成 SEO 页面

```powershell
npm run generate:seo
```

## 部署

这是一个静态站，可直接部署到 Vercel。部署目录选择本目录，Build Command 留空或使用默认静态部署。

如果使用自定义域名，建议在 Vercel 项目中添加 `ai-ark.top` 和 `www.ai-ark.top`，再按 Vercel Domains 页面给出的 DNS 记录配置。
